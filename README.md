## 🚀 Projetos em Destaque

### 📱 App Construtora - Projeto Rottas Construtora
Aplicativo mobile desenvolvido para clientes de uma construtora acompanharem seus empreendimentos, contratos, parcelas, progresso da obra e comunicações relacionadas ao empreendimento.

O projeto foi desenvolvido durante minha atuação na **SILVA NM CONSULTORIA**, em um projeto realizado para a **Rottas Construtora**.

#### Funcionalidades
* Visualização de contratos e informações do empreendimento.
* Consulta de parcelas futuras.
* Geração de boletos para pagamento.
* Acompanhamento do progresso da obra através de fotografias.
* Galeria de imagens da construção.
* Área de notificações e comunicados.
* Recebimento de notificações push.

#### Tecnologias
* React Native
* TypeScript
* React Navigation
* Tailwind
* OneSignal
* APIs REST
* Git / GitHub

#### Aspectos técnicos
* Organização do projeto através da separação entre screens, components e services.
* Desenvolvimento de componentes reutilizáveis.
* Integração com APIs backend.
* Gerenciamento de estado da aplicação.
* Integação com OneSignal para notificações push.
* Armazenamento e gerenciamento das notificações recebidas no aplicativo.

O código relacionado ao projeto profissional possui restrições de acesso. O repositório disponibilizado neste perfil apresenta o projeto conforme o conteúdo que pode ser divulgado publicamente.
